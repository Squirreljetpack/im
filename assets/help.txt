im — immediate mood, journal, and task tracker

Usage:
  im <mood> [. [body]]                           log a mood (with an optional body)
  im %<duration>                                 start a timed session
  im [-<tracker> [value]]... [mood]              add one or more custom tracker records
                                                        (optionally attached to a mood)

  im ! [name] [@<time>]                          create a task (interactive without a name)
  im ! %[<duration>] [name]                      create a recurring task (interactive)
  im ! @[<time>] [:<name>] [%<duration>]         scheduled a task (interactive if partial)
  im +[task] [count]                             edit or update a task by its reference
                                                        (see `im -vh`)

Views:
  im @[date]                                     today view
  im @due[:t|:w]                                 due view
                                                        (today / tomorrow / this week)
  im @[:o|:O]                                    pending tasks
  im @done[:o|:O]                                completed tasks
                                                        (all / oneshot / recurring+scheduled)

Trackers and grids:
  im :[week|month|year] [ids]                    dot-sequence tracker grid
                                                        ids: <tracker> or @<recurring name>
                                                        period defaults to "week"

Other:
  im :config | :c [file]                         open the config in $VISUAL / $EDITOR
                                                        file: moods | colors
  im -                                           browse trackers
  im :embed                                      embed stdin lines (one vector/line)
  im :color <mood>                               projected mood color diagnostic
  im :clear [@<date>]                            clear all mood entries from a day
  im :db prune                                   delete completed and expired tasks
  im :db backfill                                compute and persist missing mood embeddings
  im :db doctor                                  check and repair database

Sync:
  im :auth register|login|status|logout          manage the device's syncing account 
  im :sync                                       push local changes, pull remote changes
  im :sync --reset                               rebuild database from remote state

Flags:
  im -q | -v <command>                           quiet / verbose; flags go first
  im --help | -h                                 show this help (-v applies)
