im — immediate mood, journal, and task tracker

Usage:
  im <mood> [. [body]]                           log a mood (with an optional body)
  im %<duration>                                 start a timed session
  im [-<tracker> [value]]... [mood]              add one or more custom tracker records
                                                        (optionally attached to a mood)

  im ! [name] [@<time>]                          create a task (interactive without a name)
  im ! %[<interval>] [[:]name]                   create a recurring task (interactive)
  im ! @[<time>] [:<name>] [%<duration>]         scheduled a task (interactive if partial)
  im +[task] [count]                             edit or update a task by its reference
                                                        (see `im -vh`)

Views:
  im @[date]                                     today view
  im @due[:t|:w]                                 due view
                                                        (today / tomorrow / this week)
  im @[:o|:O]                                    pending tasks
  im @done[:o|:O]                                completed tasks
                                                        (all / oneshot / recurring+scheduled)

Trackers and grids:
  im :[week|month|year] [ids]                    dot-sequence tracker grid
                                                        ids: <tracker> or @<recurring name>
                                                        period defaults to "week"

Other:
  im :tool embed|mood|clear|..                   (see `im :tool --help`)
  im :tool config | :c [moods|colors]            open the config in $VISUAL / $EDITOR
  im -                                           browse trackers
  im :db prune|backfill|doctor                   database utilities

  im :sync [register|login|status|logout]        setup/manage/run sync 


Flags:
  im -q | -v <command>                           quiet / verbose; flags go first
  im --help | -h                                 show this help (-v applies)
